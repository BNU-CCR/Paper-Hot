仓库采用前后端分离的双模块结构：`backend/` 提供可安装的 Python 包 `journal_tracker`（由 `pyproject.toml` 暴露 `journal-tracker` CLI），负责从 OpenAlex/Crossref 抓取期刊论文、SQLite 存储与状态管理、AI 筛选、热点分析与公开导出；`frontend/` 基于 Next.js App Router 构建静态站点，仅消费 `frontend/public/data/papers.json` 与 `all_papers.json` 两个 JSON 快照，实现构建时预渲染、无运行时依赖。前后端通过 JSON 文件松耦合对接，后端命令 `export-public` / `update-public` 生成前端可直接读取的数据文件。`docs/` 集中项目地图、路线图与自动化部署说明，`AGENTS.md` 与 `CLAUDE.md` 分别约束前端 UI 规范与 Agent 行为。CI（GitHub Actions）统一运行 Python 测试、构建前端并部署到 GitHub Pages，Windows/macOS/Linux 的定时任务脚本则驱动 `weekly-run` 工作流完成周期性更新。
