- 后端所有功能通过 `journal_tracker.main` 子命令暴露，CLI 参数统一使用 argparse 风格命名（如 `--limit-per-journal`、`--screen-limit`）。
- 外部 API 密钥与敏感配置统一放在 `.local/key.env`，通过环境变量注入，禁止硬编码或提交到版本库。
- 前端组件全部使用 TypeScript（`.tsx`/`.ts`，strict: true），样式通过 Tailwind CSS v4 的 CSS 变量（`--background`、`--radius` 等）统一管理主题。
- 前端数据获取遵循 RSC-first 原则：构建时由 server component 读取 `public/data/*.json` 预渲染，交互逻辑拆入 client component（`"use client"`）。
- 前后端通过 `frontend/public/data/papers.json` 与 `all_papers.json` 两个只读 JSON 文件解耦，后端负责生成，前端仅消费。
