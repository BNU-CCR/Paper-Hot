该模块由三个独立脚本组成，按平台分工协作：`register_weekly_task.ps1` 通过 Windows Scheduled Task API（`Register-ScheduledTask`）将 `run_weekly.ps1` 注册为周期性任务；`run_weekly.ps1` 是核心编排脚本，负责创建日志目录、使用 `Start-Transcript` 记录输出、调用 `python -m journal_tracker.main weekly-run` 执行 Python 端逻辑，并在可选时通过 git 提交并推送前端公开数据；`run_tracker.sh` 是 Unix 平台的等价入口，自动激活 `venv` 或 `.venv` 虚拟环境后直接运行 `journal_tracker.main`。依赖方向单向指向项目根目录的 `backend/` 和 `frontend/public/data/`，脚本之间通过参数透传耦合，无共享库。
