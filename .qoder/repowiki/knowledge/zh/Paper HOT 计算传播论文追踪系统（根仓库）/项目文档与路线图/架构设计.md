该模块是纯文档集合，按职责划分为三个层次：根级活跃文档（`roadmap.md` 维护唯一 TODO/阶段路线、`project-map.md` 描述仓库文件地图、`workspace-structure-review.md` 记录结构清理决策、`automation.md` 说明 GitHub Actions 与 Windows Task Scheduler 自动化）；`archive/` 子目录按时间戳分组存放历史规划与设计稿（如 `2026-05-10-architecture-review/` 架构审计、`2026-05-static-site-design/` 静态站设计），作为非当前事实来源的归档；文档之间通过交叉引用形成单一真相源约定——`README.md` 为入口、`roadmap.md` 为唯一 TODO、`project-map.md` 为文件定位、`archive/` 存放历史版本。
