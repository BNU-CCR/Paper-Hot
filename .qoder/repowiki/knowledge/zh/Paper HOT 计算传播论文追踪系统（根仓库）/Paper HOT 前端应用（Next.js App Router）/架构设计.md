应用以 `app/` 为根目录采用 Next.js App Router 的分页式路由组织：`layout.tsx` 作为根布局注入全局样式（globals.css、library.css、sidebar.css、masonry.css），各功能页面（home、about、journals、hotspots）通过导入 `components/` 下的业务组件和 `lib/data.ts` 中的构建期数据读取函数获取 JSON 快照，再交由 `types/` 中定义的 Paper/Journal/Hotspot 类型约束数据结构。`components/ui/` 提供基于 Radix 的基础 UI 原语，被上层业务组件复用；`lib/utils.ts` 与 `data-url.ts` 提供跨模块工具。页面与服务端组件之间通过 TypeScript 类型契约通信，无运行时状态管理，数据流单向从 `lib/data.ts` → 页面组件 → 展示组件。
