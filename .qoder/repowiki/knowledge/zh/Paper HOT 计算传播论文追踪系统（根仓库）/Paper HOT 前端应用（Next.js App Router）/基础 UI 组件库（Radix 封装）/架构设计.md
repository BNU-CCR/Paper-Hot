该模块是一组独立的 React 函数式组件文件，每个文件对应一个 UI 组件或一组相关子组件（如 select.tsx 导出 Select/SelectContent/SelectTrigger 等）。所有组件均通过 `@radix-ui/react-*` 原语进行无障碍封装，并通过 `../../lib/utils` 中的 `cn` 工具合并 className。样式层采用 Tailwind CSS + class-variance-authority（cva）组合：button.tsx 使用 cva 定义 variant/size 变体，其余组件以内联 className 字符串为主。交互型组件（select、sheet、tabs、collapsible）顶部标注 `"use client"` 以支持客户端状态；纯展示型组件（button、input）无此标记。依赖方向单向向下：组件仅依赖 `@radix-ui/*`、`lucide-react` 图标和 `lib/utils`，不反向依赖业务代码。
