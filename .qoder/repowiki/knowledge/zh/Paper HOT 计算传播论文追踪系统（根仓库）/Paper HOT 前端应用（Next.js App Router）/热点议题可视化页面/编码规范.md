- 服务端组件与客户端组件职责分离：`page.tsx` 仅做数据获取与条件渲染，交互逻辑全部放入带 "use client" 的 `page-client.tsx` 及子组件中。
- 所有需要 DOM 访问或事件监听的组件均使用 "use client" 指令，并通过 `useEffect` 配合 ref 管理第三方库实例的生命周期，在清理函数中调用 `.kill()` 或 `disconnect()` 释放资源。
- 主题色通过 CSS 变量读取（`cssVar` 辅助函数）而非硬编码，使图谱颜色随 `data-theme` 属性自动响应。
- 外部数据请求统一通过 `publicDataUrl` 构造 URL，并使用 `let cancelled = false` 模式在组件卸载时取消未完成的 fetch。
- 空数据状态统一使用带有 `empty-state` class 的提示区块，文案遵循「暂未生成 / 等待下一次自动更新」的固定句式。
