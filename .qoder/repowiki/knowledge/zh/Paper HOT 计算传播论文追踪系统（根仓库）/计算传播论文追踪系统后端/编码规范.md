- 所有子模块通过 config.get_config() 获取全局 Config 单例，避免重复初始化
- 对外部 API 调用统一使用 SEARCH_PAUSE_SECONDS 休眠控制请求频率
- 错误处理采用 try/except 捕获后调用 storage.mark_filter_error 记录状态而非直接抛出
- CLI 子命令统一通过 argparse subparsers 注册，并在 main() 中按命令分发到对应函数
- 数据导出路径统一从 config.public_data_dir 派生，确保前端可访问
- YAML 配置文件采用 yaml.safe_load 加载并默认空字典回退，保证向后兼容
