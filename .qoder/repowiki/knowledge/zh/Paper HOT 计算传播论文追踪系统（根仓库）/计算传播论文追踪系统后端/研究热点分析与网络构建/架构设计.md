本模块由三个职责清晰的文件组成：
- `hotspots.py`：基于 Anthropic Claude 的轻量级月度热点聚合器 `MonthlyHotspotGenerator`，将最近30天公开论文摘要压缩为 JSON Lines 发送给 LLM，再对返回的 topics 做严格结构校验（标题去重、paper_ids 必须在候选集中、至少3个议题），最终写入 `public_data_dir/hotspots.json`。
- `hotspot_network.py`：完整的热度网络流水线，按注释分10步实现——加载候选论文 → FastEmbed 文本嵌入（带 `paper_features` 缓存）→ 互斥 kNN 语义图 → 叠加主题/参考文献 Jaccard 边权形成混合图 → Leiden 社区检测 → 与历史 topic 通过匈牙利算法匹配保持 lineage_id → 计算增长/体量/扩散/时效/质量五维加权热度分数 → igraph Fruchterman-Reingold 固定2D布局 → 调用 `TopicLabeler` 生成中文标签 → 原子替换写入 `graph.json`、`trends.json`、`manifest.json` 及每个 topic 的 detail 文件。
- `hotspot_validation.py`：在原子替换前对 temp 目录执行 schema 校验（必需文件、节点数范围、坐标有限性、边引用完整性、detail 文件存在性等），错误抛出 `HotspotValidationError`，警告仅记录不中断流程。
依赖方向单向：`hotspot_network.py` 依赖 `storage.PaperStorage`、`config.Config`、`hotspot_labels.TopicLabeler`；`hotspots.py` 依赖 `publication.PublicPaperExporter`；两者均不互相依赖，validation 独立运行于产出目录之上。
