模块由三个 Python 文件与一组 YAML 配置文件组成，职责清晰分层：
- `storage.py` 定义 `Paper` 与 `PaperFeatures` 两个 dataclass 作为领域模型，并通过 `PaperStorage` 类封装 SQLite 操作（建表、索引、CRUD、统计、CSV 导出），使用 `_get_connection` 上下文管理器保证连接安全，通过 `_ensure_columns` 实现数据库 schema 向后兼容迁移。
- `config.py` 的 `Config` 类集中加载 `journals.yaml`、`prompts.yaml`、`settings.yaml` 及可选的 `topic_overrides.yaml`，并按 `.env`/`key.env` → 环境变量 → settings.yaml 的优先级解析 API Key 与模型参数，同时暴露 `data_dir`、`database_path`、`public_data_dir` 等路径属性。
- `coverage.py` 基于 `requests` 调用 Crossref Works API，通过 `CrossrefClient` 与 `CoverageVerifier` 对比本地 OpenAlex 红榜论文与 Crossref DOI 的覆盖差异，输出 JSON 报告。
- `backend/config/` 下的四个 YAML 文件是纯数据驱动配置：`journals.yaml` 维护红榜期刊元数据（ISSN、OpenAlex ID、优先级等），`prompts.yaml` 存放 AI 筛选与热点归纳的 prompt 模板，`settings.yaml` 控制数据库路径、调度器、日志、热点网络参数等，`topic_overrides.yaml` 支持主题人工重命名与合并。
依赖方向单向：`coverage.py` 依赖 `storage.PaperStorage`；`config.py` 不依赖其他模块；`storage.py` 仅依赖标准库。
