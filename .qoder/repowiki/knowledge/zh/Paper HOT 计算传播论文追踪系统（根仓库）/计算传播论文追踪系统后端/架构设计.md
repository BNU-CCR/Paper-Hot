本模块由 journal_tracker/ 子包与 backend/config/ 配置文件共同构成，采用「CLI 编排层 + 功能子模块 + 共享配置」的分层结构：
- 编排层：main.py 通过 argparse 暴露 search / export-public / weekly-run / build-hotspot-network / verify-coverage 等子命令，每个子命令实例化 Config 并串联 storage、discovery、filter、notification、publication、hotspots 等子模块。
- 数据层：storage.PaperStorage 提供 SQLite 持久化（papers 表 + paper_features 扩展表），被 discovery、filter、publication、hotspot_analysis 等模块共同读写；config.Config 通过 get_config() 全局单例向所有子模块注入 API Key、数据库路径、公开目录等。
- 外部集成：discovery_filter 负责 Semantic Scholar/OpenAlex 抓取与 Anthropic 兼容 API 筛选；hotspot_analysis 基于嵌入+kNN+Leiden 生成静态 JSON；publication_notification 将结果导出为 public/data/papers.json 并通过 Server酱/邮件推送；storage_config 统一加载 journals.yaml、prompts.yaml、settings.yaml、topic_overrides.yaml。
- 启动时序：weekly-run 子命令按固定顺序执行 ingest_journal_updates → repair_local_screening_queue → screen_pending_papers（多批）→ update_public_workflow → generate_monthly_hotspots → verify_coverage，并将运行报告写入 data/reports/weekly_run_*.json。
