`readme_update.py` 可通过 `python -m backend.journal_tracker.readme_update` 或直接执行，默认读取项目根 `README.md`、`frontend/public/data/papers.json`、`frontend/public/data/all_papers.json` 及 `backend/data/reports/weekly_run_latest.json`，也可通过 `--readme`、`--featured`、`--all-papers`、`--report` 参数覆盖路径。微信通知需配置 `notification_config.serverchan_sckey` 与 `enable_wechat=true`。
