本模块由三个相互独立的脚本式子模块组成，均面向 journal_tracker 上层流程提供输出能力：
- `publication.py` 定义 `PublicPaperExporter` 类，依赖 `storage.PaperStorage` 获取公开论文，按固定字段映射序列化并写入 JSON 文件（支持 `export_json` 与 `export_all_journal_updates_json` 两种导出）。
- `notification.py` 定义 `NotificationSender` 类，通过 `config.get_config()` 读取 `notification_config`，封装 Server酱 HTTPS 调用实现微信通知，并提供占位的 `send_email` 与批量聚合发送接口 `send_batch_notification`。
- `readme_update.py` 提供纯函数式工具集（`render_preview`、`render_stats`、`replace_section`、`update_readme`），通过 `<!-- paper-hot:auto-preview:start/end -->` 和 `<!-- paper-hot:auto-stats/start/end -->` 注释标记定位 README 区块进行原地替换，并通过 `argparse` 暴露 CLI 入口 `main()`。
依赖方向单向向外：`publication` 依赖 storage 层，`notification` 依赖 config 层，`readme_update` 仅依赖标准库与 JSON 数据文件，三者之间无互相引用。
