测试目录采用扁平结构，每个被测模块对应一个 `test_*.py` 文件，全部使用 Python 标准库 `unittest.TestCase` 组织。测试通过 `TemporaryDirectory` + 写入 YAML/JSON 配置的方式构造隔离的运行环境，避免对真实文件系统或外部 API 的依赖；对外部服务（如 OpenAlexDiscovery、MonthlyHotspotGenerator）统一通过 `unittest.mock.Mock` 和 `patch` 进行替换。测试按功能域划分：`test_config.py` 验证配置加载与环境变量覆盖优先级，`test_openalex_discovery.py` 验证 OpenAlex API 查询构建与字段映射，`test_storage_workflow.py` 验证 PaperStorage 的数据库操作与 CSV 导出，`test_hotspot_network.py` 在缺少 numpy/scipy/scikit-learn/igraph 时通过 `@unittest.skipUnless` 跳过分析依赖，`test_journal_workflow.py` 和 `test_storage_workflow.py` 则模拟 CLI 入口 `journal_tracker.main.main()` 以端到端验证 `fetch-journals`、`verify-coverage`、`weekly-run` 等子命令。所有测试均不修改仓库内真实数据，输出路径指向临时目录下的 `data/` 子目录。
