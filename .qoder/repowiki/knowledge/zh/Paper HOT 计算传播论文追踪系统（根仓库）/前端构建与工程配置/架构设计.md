该模块仅包含四个顶层配置文件，作为整个前端工程的构建与运行契约：
- `package.json` 定义项目元信息、脚本命令（dev/build/start/typecheck）以及运行时与开发时依赖，核心框架为 Next.js 16 + React 19。
- `tsconfig.json` 启用严格模式与 isolatedModules，使用 esnext moduleResolution 和 bundler 解析策略，通过 paths 映射 `@/*` 到根目录，集成 Next.js TypeScript 插件。
- `next.config.mts` 将应用配置为纯静态导出（output: export），开启图片未优化与尾部斜杠，并通过 GITHUB_ACTIONS 环境变量区分 GitHub Pages 部署路径 `/Paper-Hot` 与本地空 basePath。
- `postcss.config.mjs` 接入 `@tailwindcss/postcss` 插件，配合 tailwindcss v4 完成样式处理。
依赖方向单一向下：所有配置均指向 Node 生态工具链，无内部子模块耦合。
